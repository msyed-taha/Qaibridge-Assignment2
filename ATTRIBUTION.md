# Qaibridge code reuse

This assignment application reuses selected simulator-kernel source files from the student's Qaibridge final-year project:

- `app/quantum_kernel/circuit.py`
- `app/quantum_kernel/gates.py`
- `app/quantum_kernel/memory_manager.py`
- `app/quantum_kernel/state_vector.py`

The learning challenges are a reduced adaptation of the circuit-builder challenge concepts. Authentication, email, AI services, the full frontend, and unrelated FYP modules are intentionally excluded.
